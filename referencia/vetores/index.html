    Vetores¶

    vector ¶

    Vector and FeatureCollection helpers for SIMIDS.

    This module gives SIMIDS a small Earth Engine / geemap-like layer registry: load vector or georeferenced tabular data once, give it a name, and reuse it later for raster sampling, kriging, machine learning and plotting.

    Named vector layer stored inside a SIMIDS client session.

    columns property ¶

    Attribute column names.

    bounds property ¶

    bounds: tuple[float, float, float, float] | None

    (minx, miny, maxx, maxy) in the layer CRS, or None when empty.

    load_features(source: str | Path | DataFrame | Any, name: str | None = None, layer: str | int | None = None, x_col: str | None = None, y_col: str | None = None, crs: str | None = None, target_crs: str | None = None, register: bool = True, **kwargs: Any)

    Load vector/CSV features and optionally register them in the client.

    Examples:

    farm = simids.load_features('limite_fazenda.shp', name='fazenda') soil = simids.load_features('solo.csv', name='solo', x_col='lon', y_col='lat') points = simids.load_features(df, name='amostras', x_col='longitude', y_col='latitude')

    table_to_features ¶

    table_to_features(data: DataFrame | str | Path, x_col: str | None = None, y_col: str | None = None, crs: str = 'EPSG:4326', target_crs: str | None = None, drop_missing_xy: bool = True, **read_csv_kwargs: Any)

    Convert a table with coordinate columns into a GeoDataFrame.

    Parameters:

    Name Type Description Default
    data DataFrame | str | Path

    Either a pandas DataFrame or a CSV path.

    		 required
    x_col str | None

    Coordinate columns. If omitted, common names like lon/lat, longitude/latitude, x/y and coord_x/coord_y are detected automatically.

    		 None
    y_col str | None

    Coordinate columns. If omitted, common names like lon/lat, longitude/latitude, x/y and coord_x/coord_y are detected automatically.

    		 None
    crs str

    CRS of the coordinate columns. Use EPSG:4326 for lon/lat or the UTM EPSG code when x/y are projected coordinates.

    		 'EPSG:4326'
    target_crs str | None

    Optional CRS to reproject the output.

    		 None
