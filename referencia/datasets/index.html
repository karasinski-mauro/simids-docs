    filter_images ¶

    filter_images(df: DataFrame, object_key_col: str = 'object_key', date_from: str | Timestamp | None = None, date_to: str | Timestamp | None = None, dates: Any = None, year: int | list[int] | None = None, month: int | list[int] | None = None, property_id: Any = None, height: Any = None, equipment: Any = None, plot_id: Any = None, band: Any = None, indices: Any = None, band_group: Any = None, area: Any = None, extension: Any = None, bucket: Any = None, bucket_col: str = 'bucket', valid_names_only: bool = True, valid_only: bool = False, dataset_id: str | None = None, max_tests: int | None = None, validation_max_size: int = 128, keep_validation_errors: bool = True, drop_duplicates: bool = True, prefix: str = 'file_') -> DataFrame

    Filtra rows de imagem usando metadados SIMIDS codificados no nome do arquivo.

    O nome de arquivo SIMIDS segue o padrão::

    y_{YYYYMMDD}_i_{id}_s_{sitio}_h_{altura}_e_{equip}_t_{talhao}_b_{banda}_a_{area}.ext

    Cada segmento corresponde a um parâmetro de filtro abaixo.

    Parâmetros

    date_from: Data mínima de captura. Ex: "2024-01-01". date_to: Data máxima de captura. Ex: "2024-12-31". dates: Data(s) exata(s) de captura. Ex: "2024-06-15" ou lista de datas. year: Ano(s) de captura. Ex: year=2024 ou year=[2023, 2024]. month: Mês(es) de captura (1–12). Ex: month=6 ou month=[6, 7, 8]. property_id: ID do sítio/propriedade (campo s_ do nome). Ex: property_id=12. height: Altura(s) de voo em metros (campo h_). Ex: height=50 ou height=[30, 50]. equipment: Código ou nome do equipamento (campo e_). Ex: "MS" (multiespectral drone), "PS" (Planet Scope), "HS" (hiperespectral). plot_id: ID do talhão (campo t_). Ex: plot_id=3 ou plot_id=[1, 2, 3]. band: Banda(s) pelo código ou ID (campo b_). Ex: "NDVI", ["RGB", "NDVI"], 1. indices: Alias para band — pode ser combinado com ele. band_group: Grupo de bandas pré-definido. Opções: "vegetacao", "indices", "rgb", "agua", "satelite", "elevacao", "agricultura". area: Identificador de área (campo a_). Ex: area="total". extension: Extensão do arquivo. Ex: extension=".tif" ou [".tif", ".png"]. bucket: Bucket de armazenamento. Ex: bucket="geoserver". valid_only: Se True, mantém apenas rows cujo raster é baixável (requer dataset_id). dataset_id: Obrigatório quando valid_only=True.

    Exemplos

    simids.filter_images(df, band="NDVI", year=2024) simids.filter_images(df, band_group="vegetacao", month=[6, 7, 8]) simids.filter_images(df, band=["RGB", "NDVI"], date_from="2024-01-01") simids.filter_images(df, equipment="MS", height=50, plot_id=[1, 2], year=2024) simids.filter_images(df, property_id=12, band_group="indices", date_from="2024-06-01", date_to="2024-08-31")

    load_dataset ¶

    load_dataset(dataset_id: str, expand: bool = True, save_csv: str | None = None, refresh: bool = False, cache_dir: str | Path = CACHE_DIR, **kwargs: Any) -> DataFrame

    Load a dataset as a pandas DataFrame.

    The rows are saved in the dataset folder (.simids/datasets/<dataset>) like :meth:load_images. Use refresh=True to download them again from the API.

    df = simids.load_dataset("sensor-import:123")

    load_images ¶

    load_images(dataset_id: str, refresh: bool = False, cache_dir: str | Path = CACHE_DIR) -> DataFrame

    Load the image catalog of a dataset: one row per raster file, with file-name metadata.

    The catalog is saved in the dataset folder (.simids/datasets/<dataset>), so later calls are instantaneous. Use refresh=True to download it again from the API. The dataset_id is remembered, so raster functions accept catalog rows directly.

    imgs = simids.load_images("sensor-import:123")

    scenes ¶

    scenes(df: DataFrame, require: Iterable[str] | None = None, check_access: bool = False) -> DataFrame

    One row per scene (image_id) with its date, place and available bands.

    require keeps only scenes that have all the given bands, e.g. simids.scenes(imgs, require=["NIR", "RED", "NDVI"]). Newest first.

    check_access=True adds an acessivel column telling whether the files of those bands really exist in storage (one light request per file).

    file_names ¶

    Utilities to parse and filter SIMIDS generated file names.

    The expected file name pattern is documented in FILE_NAME_DICTIONARY.md::

    y_{YYYYMMDD}_i_{id}_s_{propertyId}_h_{height}_e_{equipment}_t_{plotId}_b_{band}_a_{area}{ext}

    These helpers are intentionally independent from API calls, so they can be used with any dataframe that has an object_key or file-name column.

    parse_simids_filename ¶

    parse_simids_filename(filename: str | Path | None) -> dict[str, Any]

    Parse a SIMIDS generated file name into metadata fields.

    Returns an empty dictionary when the name does not match the expected convention. Numeric codes are kept as strings and also converted to nullable integer columns later by :func:enrich_file_metadata.

    filter_file_metadata ¶

    filter_file_metadata(df: DataFrame, object_key_col: str = 'object_key', date_from: str | Timestamp | None = None, date_to: str | Timestamp | None = None, dates: Any = None, year: int | list[int] | None = None, month: int | list[int] | None = None, property_id: Any = None, height: Any = None, equipment: Any = None, plot_id: Any = None, band: Any = None, indices: Any = None, band_group: Any = None, area: Any = None, extension: Any = None, bucket: Any = None, bucket_col: str = 'bucket', valid_names_only: bool = True, drop_duplicates: bool = True, prefix: str = 'file_') -> DataFrame

    Filtra um dataframe usando metadados codificados nos nomes de arquivo SIMIDS.

    Parâmetros

    band: Banda(s) pelo código ("NDVI", "RGB") ou ID numérico (1, 10). Aceita string, lista ou conjunto. indices: Alias para band. Pode ser combinado: band="RGB", indices=["NDVI","NDRE"]. band_group: Filtra por grupo de bandas pré-definido. Grupos disponíveis: "vegetacao", "indices", "agua", "rgb", "satelite", "elevacao", "hsv", "cmyk", "agricultura". year: Filtra pelo ano de captura. Ex: year=2024 ou year=[2023, 2024]. month: Filtra pelo mês de captura (1–12). Ex: month=6 ou month=[6, 7, 8]. date_from: Data mínima de captura. Ex: "2024-01-01". date_to: Data máxima de captura. Ex: "2024-12-31". dates: Datas exatas de captura. Ex: "2024-06-15" ou ["2024-06-15", "2024-07-01"]. equipment: Equipamento pelo código ou nome. Ex: "PS", "MS", "LiDAR".

    Exemplos

    filter_file_metadata(df, band="NDVI", year=2024) filter_file_metadata(df, band_group="vegetacao", month=[6, 7, 8]) filter_file_metadata(df, band=["RGB", "NDVI"], date_from="2024-01-01")
