    add_layer ¶

    add_layer(layer: Any, vis_params: dict[str, Any] | None = None, name: str | None = None, shown: bool = True, opacity: float = 1.0) -> 'Map'

    Add a GeoArray (raster) or GeoDataFrame (vector) to the map, like geemap's addLayer.

    vis_params for rasters:

    • min / max: value range of the color scale (default: percentiles 2–98).
    • palette: matplotlib colormap name ("RdYlGn") or list of colors.
    • bands: three band positions (0-based) to show as RGB for multi-band arrays.

    m = simids.Map() m.add_layer(ndvi, {"min": 0, "max": 1, "palette": "RdYlGn"}, "NDVI calculado")

    drawmap ¶

    Interactive ipyleaflet map to draw areas of interest, like geemap's Map.user_roi.

    DrawMap ¶

    DrawMap(location: tuple[float, float] = (-9.97, -67.81), zoom_start: int = 12, height: str = '600px')

    Map where the user draws polygons/rectangles; the drawings come back as m.roi.

    Uses ipyleaflet (Jupyter widgets), so the drawn geometry reaches Python, which a static folium map cannot do. The layer API matches :class:simids.Map.

    m = simids.DrawMap() m.add_layer(ndvi, {"min": 0, "max": 1, "palette": "RdYlGn"}, "NDVI") m # desenhe no mapa roi = m.roi

    roi property ¶

    roi

    Drawn areas as a GeoDataFrame (EPSG:4326), one row per shape, with area_ha.

    add_layer ¶

    add_layer(layer: Any, vis_params: dict[str, Any] | None = None, name: str | None = None, shown: bool = True, opacity: float = 1.0, max_size: int | None = 1000, resampling: str = 'nearest') -> 'DrawMap'

    Add a GeoArray (raster), GeoDataFrame (vector) or :class:simids.collection.Image.

    vis_params are the same as :meth:simids.Map.add_layer. For an Image (one band, e.g. img.select("NDVI")) the band is loaded with max_size and resampling ("nearest" is fast; "average" is smoother but reads the whole file) and, without vis_params, uses the band's default colors.

    add_time_slider ¶

    add_time_slider(collection: Any, band: str = 'NDVI', vis_params: dict[str, Any] | None = None, max_size: int | None = 1000, opacity: float = 1.0, resampling: str = 'nearest', prefetch: int = 2) -> 'DrawMap'

    Slider to walk through the dates of a collection, like geemap's add_time_slider.

    The newest date is shown first; then the other dates are downloaded in the background, prefetch at a time (newest to oldest), so moving the slider is instant once they are ready. prefetch=0 downloads a date only when it is selected.

    m.add_time_slider(col, "NDVI")

    center_object ¶

    center_object(layer: Any) -> 'DrawMap'

    Center on a GeoArray or GeoDataFrame, like Map.centerObject.

    center_on ¶

    center_on(bounds: tuple[float, float, float, float]) -> 'DrawMap'

    Center and zoom the map on (left, bottom, right, top) in EPSG:4326.

    Computed in Python, so it works before the map is displayed (ipyleaflet's fit_bounds only works on a map already on screen).

    example_roi ¶

    example_roi(raster: Any, size_m: float = 100)

    Square area of size_m meters on a valid pixel near the middle of raster.

    Handy to run a notebook end to end before drawing an area on the map.
