    Convenção de nomes de arquivo¶

    Os arquivos raster do SIMIDS carregam os metadados no nome. A legenda de índices (PDF) mostra o mesmo conteúdo em formato visual.

    y_{AAAAMMDD}_i_{id}_s_{propriedade}_h_{altura}_e_{equipamento}_t_{talhão}[_p_{produto}]_b_{banda}_a_{área}.ext

    Exemplo: y_20250729_i_lf3k2ab1x_s_42_h_50_e_3_t_1232_b_1_a_Total.tif — imagem NDVI (b_1) de 29/07/2025, propriedade 42, voo a 50 m com câmera multiespectral (e_3), talhão 1232, área total.

    Segmento Campo Coluna no catálogo
    y_ data de captura (AAAAMMDD) file_capture_date, file_capture_year/month/day
    i_ identificador do upload — o mesmo para todos os arquivos de um upload multibanda file_image_id
    s_ propriedade (sítio) file_property_id, file_property_id_int
    h_ altura de voo em metros (arredondada) file_height, file_height_m
    e_ equipamento file_equipment, file_equipment_name
    t_ talhão file_plot_id, file_plot_id_int
    p_ produto (opcional, versões recentes) file_product_id
    b_ banda ou índice (padrão: 0) file_band, file_band_code, file_band_description
    a_ área parcial (padrão: Total) file_area

    Nomes que não seguem o padrão ficam com file_is_valid_simids_filename = False.

    Use simids.parse_simids_filename(nome) para um nome avulso e simids.enrich_file_metadata(df) para uma tabela.

    Equipamentos (e_)¶

    Valor Equipamento
    2 Planet Scope
    3 Multiespectral/RGB
    HS Hiperespectral
    LD LiDAR
    PL Plantadeira
    CL Colheitadeira
    CD Condutividade
    AS Análise de solo

    Nos filtros também valem os nomes e siglas: "MS", "multiespectral", "PS", "Planet Scope", "LiDAR"…

    Multiespectral × RGB

    As câmeras multiespectral (MS) e RGB (ME) gravam o mesmo valor, e_3. O nome sozinho não distingue as duas; use o campo b_.
