    Funções do módulo simids¶

    Depois de simids.initialize(), cada método da conexão fica disponível direto no módulo: simids.load_images(...) é o mesmo que simids.initialize().load_images(...). Esta página lista essas funções; clique para ver a documentação completa.

    Além delas, o módulo exporta classes e funções que não dependem da conexão: ImageCollection, Image, GeoArray, Map, DrawMap, SensorDashboard, example_roi, read_features, table_to_features, FeatureLayer, parse_simids_filename, enrich_file_metadata, filter_file_metadata, SENSOR_FIELD_GROUPS, além de initialize, authenticate, get_client, clear_credentials, load_credentials e save_credentials.

    Datasets e catálogo¶

    Função Descrição
    simids.list_datasets List available datasets.
    simids.load_dataset_rows Load paginated rows for a dataset.
    simids.expand_row_data Expand a nested row_data column into normal dataframe columns.
    simids.enrich_file_metadata Add metadata parsed from SIMIDS generated file names.
    simids.filter_images Filtra rows de imagem usando metadados SIMIDS codificados no nome do arquivo.
    simids.load_dataset Load a dataset as a pandas DataFrame.
    simids.load_images Load the image catalog of a dataset: one row per raster file, with file-name metadata.
    simids.ImageCollection Earth Engine–style collection of a dataset (id) or of an image catalog DataFrame.
    simids.image_summary Overview of an image catalog: number of files, scenes, bands, dates, properties...
    simids.list_bands Band types present in the catalog, with the number of files of each.
    simids.scenes One row per scene (image_id) with its date, place and available bands.

    Rasters¶

    Função Descrição
    simids.raster_url Return a temporary (presigned) URL for a raster, or the path if it is a local file.
    simids.download_raster_bytes Download the full raster file. Prefer :meth:open_raster, which streams only what is read.
    simids.rasters_exist :meth:raster_exists for many catalog rows at once.
    simids.raster_exists Check, without downloading, whether a raster file really exists in storage.
    simids.open_raster Open a raster with rasterio without downloading the whole file.
    simids.load_raster Load a raster as a :class:GeoArray (float32, nodata → NaN).
    simids.load_bands Load several bands of the same scene, aligned on a common pixel grid.
    simids.zonal_stats Pixel statistics of a single-band raster inside each area of roi.
    simids.normalize_image Normalize image with percentile clipping.
    simids.apply_colormap Apply matplotlib colormap to a single-band raster.
    simids.inspect_raster Inspect raster metadata and band statistics (computed on a reduced preview).
    simids.suggest_display Suggest display parameters automatically.
    simids.open_raster_preview Open a raster preview. Returns (image, (left, bottom, right, top)).
    simids.plot_raster Plot a raster and return the matplotlib Axes.
    simids.validate_raster_rows Validate raster rows by downloading and opening each raster.
    simids.create_nodata_mask Cria máscara booleana onde True = pixel válido (diferente de nodata).
    simids.threshold_mask Cria máscara onde True = pixel dentro do intervalo [min_val, max_val].
    simids.mask_raster Aplica uma máscara booleana ao raster, preenchendo pixels inválidos.
    simids.open_raster_masked Baixa raster e retorna (imagem, máscara_válida, bounds) já mascarado.
    simids.find_valid_raster Find the first downloadable raster referenced by a dataframe.

    Sensores e estações¶

    Função Descrição
    simids.load_sensors Load sensor readings (soil sensors and weather station), one row per reading.
    simids.sensor_locations One point per device (its most frequent coordinate) as a GeoDataFrame in EPSG:4326.
    simids.aggregate_sensors Group sensor readings per device, by day or in 30-minute slots.
    simids.cross_sensors Cross soil sensors, weather station and an image index, per flight date × soil sensor.
    simids.clean_sensors Readings ready for analysis: impossible values removed and one position per device and day.
    simids.filter_sensors The readings of an analysis: period, area and devices, applied once to all the data.
    simids.sensor_summary One row per device: type, readings, period, reading interval and last position.
    simids.weather_series Rain and temperature of the weather stations, one row per station and period.
    simids.soil_moisture Soil moisture of the soil sensors, one row per sensor and period, with the position of that period.

    Vetores¶

    Função Descrição
    simids.load_features Load vector/CSV features and optionally register them in the client.
    simids.add_feature_layer Register an existing GeoDataFrame as a named SIMIDS feature layer.
    simids.get_feature_layer Return a registered feature layer by name.
    simids.list_feature_layers List registered feature layers.
    simids.clear_feature_layers Remove all registered feature layers from the client session.
    simids.to_geodataframe Convert a vector source or coordinate table to GeoDataFrame without registering it.
    simids.feature_info Return metadata for a registered layer or GeoDataFrame.
    simids.add_xy_columns Add coordinate columns to a registered layer or GeoDataFrame.
    simids.clip_features Clip a feature layer by another polygon layer.
    simids.spatial_join_features Spatially join two registered layers or GeoDataFrames.
    simids.sample_raster_at_points Extract local/downloaded raster values at point features.
    simids.sample_simids_raster_at_points Download a SIMIDS raster and extract values at registered point features.
    simids.plot_vector Plot a registered vector layer with GeoPandas.

    Histogramas¶

    Função Descrição
    simids.raster_band_info Number of bands, data types and the bands recommended for display (single_band, rgb or multiband).
    simids.parse_simids_filename Backward-compatible wrapper around simids.file_names.parse_simids_filename.
    simids.prepare_histogram_groups Parse the file names and add comparison_key: files of the same place, height, equipment, plot, band and area on different dates.
    simids.read_raster_pixels Valid pixel values of a SIMIDS raster, one flat array per band (read at max_size).
    simids.histogram_dataframe Histogram curve of a SIMIDS raster as a table: label, band, x, y and pixel statistics.
    simids.plot_histogram Plot pixel histograms.
    simids.compare_histograms Overlay the histograms of several SIMIDS rasters.
    simids.compare_histograms_from_dataframe Overlay the histograms of the first n rasters of a catalog DataFrame (labels from label_col).
    simids.compare_histograms_by_group Overlay, by date, the histograms of one comparison_key from :meth:prepare_histogram_groups.

    Conexão¶

    Função Descrição
    simids.build_url Build an absolute API URL from a relative path.
    simids.request Run an HTTP request against the SIMIDS API.
    simids.get_json GET a JSON response.
    simids.validate_connection Validate API URL, token and workspace permission.
    simids.info Return basic client information.
