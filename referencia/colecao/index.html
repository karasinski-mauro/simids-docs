    Coleções¶

    collection ¶

    Earth Engine–style image collections over the SIMIDS catalog.

    col = simids.ImageCollection("sensor-import:123").filter(propriedade="Modelo", safra=2025) col.aggregate_array("safra") img = col.accessible().sort("data", ascending=False).first() m = simids.DrawMap() m.add_layer(img.select("NDVI"), name="NDVI")

    ImageCollection ¶

    ImageCollection(client: Any, catalog: DataFrame, bands: Iterable[str] | None = None)

    Scenes of a SIMIDS catalog, filtered like ee.ImageCollection.

    Each scene (image_id) is one flight with several band files. Filters return a new collection; nothing is downloaded until an image is added to a map or loaded with :meth:Image.load.

    filter ¶

    filter(**criteria: Any) -> 'ImageCollection'

    Keep the scenes whose catalog columns match, e.g. filter(propriedade="Modelo", safra=2025).

    Text matches ignore case and accept part of the name ("Modelo" finds "Fazenda Modelo"). safra also accepts the first year (2025 finds "2025/2026"). A list matches any of its values.

    filter_date ¶

    filter_date(start: Any = None, end: Any = None) -> 'ImageCollection'

    Scenes captured in [start, end), like ee.ImageCollection.filterDate. None leaves that side open.

    select ¶

    select(*bands: str) -> 'ImageCollection'

    Keep only these bands, e.g. select("NDVI") or select("NIR", "RED").

    accessible ¶

    accessible() -> 'ImageCollection'

    Drop the files listed in the catalog but missing from storage (checked without downloading).

    A scene stays while it has at least one of the selected bands, so a missing RGB does not hide that date's NDVI. The dropped catalog rows are kept in removidos.

    scenes ¶

    scenes() -> DataFrame

    One row per scene: date, place and bands (oldest first).

    size ¶

    size() -> int

    Number of scenes (image_id) in the collection.

    dates ¶

    dates() -> list[Timestamp]

    Capture dates of the scenes, oldest first.

    aggregate_array ¶

    aggregate_array(column: str) -> list[Any]

    Distinct values of a catalog column, e.g. aggregate_array("safra").

    sort ¶

    sort(column: str = 'data', ascending: bool = True) -> 'ImageCollection'

    Scenes ordered by a column of :meth:scenes ("data" by default), like ee.ImageCollection.sort.

    to_list ¶

    to_list() -> list['Image']

    Images in the collection order (by date when not sorted).

    first ¶

    first() -> 'Image'

    First scene in the collection order, like ee.ImageCollection.first.

    image ¶

    image(key: Any) -> 'Image'

    One scene by image_id or by date ("2025-07-07").

    series ¶

    series(roi: Any, band: str = 'NDVI', max_size: int | None = 1000, workers: int = 4) -> DataFrame

    Statistics of band inside each area of roi for every date, like ui.Chart.image.series.

    workers dates are read at the same time. Scenes that do not cover roi (flights over another part of the property) are skipped with a notice.

    serie = col.series(m.roi, "NDVI") serie.pivot_table(index="data", columns="roi", values="média").plot()

    Image ¶

    Image(client: Any, rows: DataFrame, bands: Iterable[str] | None = None)

    One scene (image_id): a set of band files from the same flight.

    label property ¶

    label: str

    Short name for maps and charts: bands and date ("NDVI 07/07/2025").

    select ¶

    select(*bands: str) -> 'Image'

    Keep only these bands of the scene, e.g. img.select("NDVI"); raises when the scene does not have them.

    load ¶

    load(max_size: int | None = 1000, roi: Any = None, resampling: str = 'average', like: Any = None) -> Any

    Read the selected band(s): one GeoArray for one band, a dict for several.

    resampling="nearest" reads only the rows it needs: much faster for previews of the big SIMIDS files (maps use it by default). like (a GeoArray) reads onto that exact pixel grid, to compare dates pixel by pixel.

    default_vis ¶

    default_vis(band: str) -> dict[str, Any]

    Default vis_params of a band code ("NDVI" → {"min": 0, "max": 1, "palette": "RdYlGn"}); empty when unknown.
