    rasters_exist ¶

    rasters_exist(rows: Iterable[Any], workers: int = 16) -> list[bool]

    :meth:raster_exists for many catalog rows at once.

    A single file refused by the API (e.g. a malformed name) counts as missing; the error is raised only when every file is refused (dataset not authorized).

    raster_exists ¶

    raster_exists(source: Any, dataset_id: str | None = None, bucket: str | None = None) -> bool

    Check, without downloading, whether a raster file really exists in storage.

    API errors (e.g. a dataset not authorized for this workspace) are raised, so they are not mistaken for missing files.

    open_raster ¶

    open_raster(dataset_id: str, object_key: str, bucket: str = 'geoserver') -> Iterator[DatasetReader]

    Open a raster with rasterio without downloading the whole file.

    Reads straight from the presigned URL, so only the header and the pixels actually requested are transferred. Falls back to a full download when the URL cannot be opened remotely.

    with simids.open_raster(dataset_id, object_key) as src: ... print(src.count, src.crs, src.width, src.height)

    load_raster ¶

    load_raster(source: Any, dataset_id: str | None = None, bucket: str | None = None, bands: int | Iterable[int] | None = None, max_size: int | None = 1000, like: GeoArray | None = None, resampling: str = 'average', name: str | None = None, roi: Any = None) -> GeoArray

    Load a raster as a :class:GeoArray (float32, nodata → NaN).

    Parameters:

    Name Type Description Default
    source Any

    A row of the image catalog (pd.Series), a one-row DataFrame, or an object_key.

    		 required
    bands int | Iterable[int] | None

    Band index (1-based) or list of indexes. None loads all bands.

    		 None
    max_size int | None

    Largest side of the returned array, in pixels. None reads full resolution.

    		 1000
    like GeoArray | None

    Another GeoArray whose grid (CRS, extent and shape) should be matched. Use it to align bands from different files pixel by pixel.

    		 None
    roi Any

    Area of interest (GeoDataFrame, shapely geometry in EPSG:4326 or GeoJSON). Only its bounding box is read (max_size then applies to the box, giving more detail) and pixels outside the shapes become NaN.

    		 None

    Examples:

    >>> nir = simids.load_raster(row_nir)
>>> red = simids.load_raster(row_red, like=nir)
>>> ndvi_aoi = simids.load_raster(row_ndvi, roi=m.roi, max_size=2000)

    load_bands ¶

    load_bands(df: DataFrame, bands: Iterable[str] = ('NIR', 'RED', 'NDVI'), image_id: str | None = None, max_size: int | None = 1000, roi: Any = None, **kwargs: Any) -> dict[str, GeoArray]

    Load several bands of the same scene, aligned on a common pixel grid.

    Bands are matched by the b_ code of the SIMIDS file name. When image_id is omitted, the most recent scene that has all requested bands is used (see :meth:scenes).

    Examples:

    >>> b = simids.load_bands(imgs, ["NIR", "RED", "NDVI"])
>>> ndvi = (b["NIR"] - b["RED"]) / (b["NIR"] + b["RED"])
>>> b_aoi = simids.load_bands(imgs, ["NIR", "RED"], roi=m.roi, max_size=2000)
>>> b_old = simids.load_bands(imgs, ["NIR", "RED"], image_id="1437", like=b["NIR"])  # same grid as b

    plot_raster ¶

    plot_raster(source: Any, object_key: str | None = None, bucket: str = 'geoserver', max_size: int = 1000, bands: tuple[int, ...] | str = 'auto', ax: Any = None, figsize: tuple[int, int] = (8, 8), normalize: bool = True, cmap: str | None = 'auto', title: str | None = None, colorbar: bool = True, **imshow_kwargs: Any) -> Any

    Plot a raster and return the matplotlib Axes.

    source can be an array/GeoArray already in memory, a catalog row, or a dataset_id followed by object_key (legacy form).

    Single-band images keep their real values (colorbar in data units), stretched between percentiles 2–98 unless vmin/vmax are given. Images with 3+ bands are shown as RGB from the first three bands.

    Examples:

    >>> fig, ax = plt.subplots(1, 2, figsize=(12, 5))
>>> simids.plot_raster(ndvi, ax=ax[0], cmap="RdYlGn", vmin=0, vmax=1, title="Calculado")
>>> simids.plot_raster(b["NDVI"], ax=ax[1], cmap="RdYlGn", vmin=0, vmax=1, title="SIMIDS")

    validate_raster_rows ¶

    validate_raster_rows(df, dataset_id: str, object_key_col: str = 'object_key', bucket_col: str = 'bucket', valid_only: bool = True, max_tests: int | None = None, max_size: int = 128, keep_errors: bool = True, show_progress: bool = True)

    Validate raster rows by downloading and opening each raster.

    This method adds these columns to the returned dataframe:

    • raster_valid: True when the raster was downloaded and opened.
    • raster_width and raster_height: raster dimensions in pixels.
    • raster_count: number of bands.
    • raster_crs: CRS as text.
    • raster_dtypes: rasterio dtype list.
    • raster_error: error message when validation fails, if requested.

    When valid_only=True, only valid rasters are returned.

    create_nodata_mask staticmethod ¶

    create_nodata_mask(img: ndarray, nodata: float = 0) -> ndarray

    Cria máscara booleana onde True = pixel válido (diferente de nodata).

    Para imagens multi-banda (H, W, bands), um pixel é válido se QUALQUER banda for diferente do valor nodata.

    Args: img: Array 2D (H, W) ou 3D (H, W, bands). nodata: Valor de nodata. Use np.nan para NaN. Padrão: 0.

    Exemplos

    img, bounds = simids.open_raster_preview(dataset_id, object_key) mask = simids.create_nodata_mask(img, nodata=0) img_float = img.astype("float32") img_float[~mask] = np.nan

    threshold_mask staticmethod ¶

    threshold_mask(img: ndarray, min_val: float | None = None, max_val: float | None = None, band: int = 0) -> ndarray

    Cria máscara onde True = pixel dentro do intervalo [min_val, max_val].

    Para imagens multi-banda, o limiar é aplicado em uma única banda.

    Args: img: Array 2D (H, W) ou 3D (H, W, bands). min_val: Valor mínimo inclusivo. None = sem limite inferior. max_val: Valor máximo inclusivo. None = sem limite superior. band: Índice da banda para aplicar o limiar em imagens 3D. Padrão: 0.

    Exemplos
    Máscara de vegetação: NDVI > 0.3¶

    mask = simids.threshold_mask(ndvi_img, min_val=0.3)

    Máscara de valores válidos em imagem uint16 normalizada¶

    mask = simids.threshold_mask(img, min_val=1, max_val=65534)

    mask_raster staticmethod ¶

    mask_raster(img: ndarray, mask: ndarray, fill: float = nan) -> ndarray

    Aplica uma máscara booleana ao raster, preenchendo pixels inválidos.

    Args: img: Array 2D (H, W) ou 3D (H, W, bands). mask: Array booleano 2D (H, W) onde True = pixel válido. fill: Valor para pixels mascarados. Padrão: np.nan.

    Retorna array float32 com pixels inválidos substituídos por fill.

    Exemplos

    img, bounds = simids.open_raster_preview(dataset_id, object_key) nodata_mask = simids.create_nodata_mask(img, nodata=0) img_clean = simids.mask_raster(img, nodata_mask)

    open_raster_masked ¶

    open_raster_masked(dataset_id: str, object_key: str, bucket: str = 'geoserver', nodata: float | None = 0, min_val: float | None = None, max_val: float | None = None, max_size: int = 1000, bands: tuple[int, ...] | str = 'auto') -> tuple[ndarray, ndarray, tuple[float, float, float, float]]

    Baixa raster e retorna (imagem, máscara_válida, bounds) já mascarado.

    Combina download + máscara de nodata + máscara de limiar em uma chamada. A máscara retornada tem True onde o pixel é válido.

    Args: dataset_id: ID do dataset. object_key: Chave do objeto no bucket. bucket: Nome do bucket. Padrão: "geoserver". nodata: Valor de nodata para mascarar. None desativa. Padrão: 0. min_val: Valor mínimo válido (inclusive). None = sem limite. max_val: Valor máximo válido (inclusive). None = sem limite. max_size: Dimensão máxima do preview em pixels. bands: Bandas a carregar, ou "auto".

    Retorna

    img : np.ndarray Imagem float32 com pixels inválidos como nan. mask : np.ndarray Máscara booleana 2D (True = pixel válido). bounds : tuple[float, float, float, float] Extensão geográfica (left, bottom, right, top).

    Exemplos

    img, mask, bounds = simids.open_raster_masked( ... dataset_id, object_key, nodata=0, min_val=1, max_val=65534 ... ) print(f"Pixels válidos: {mask.sum()} / {mask.size}")

    geoarray ¶

    Numpy array that carries its georeference (transform + CRS).

    GeoArray ¶

    Bases: ndarray

    np.ndarray with transform, crs, name and meta attributes.

    Behaves like a normal numpy array, so band math keeps the georeference::

    ndvi = (nir - red) / (nir + red)   # ndvi.crs / ndvi.bounds continuam válidos

    Single-band rasters are 2D (H, W); multi-band rasters are (H, W, bands). Slicing keeps the original transform, so bounds is only reliable for full arrays.

    bounds property ¶

    bounds: tuple[float, float, float, float] | None

    (left, bottom, right, top) in the array CRS.
