    Sensores¶

    sensor ¶

    Extensões da biblioteca simids para dados de sensores IoT.

    Campos como chegam da API (datasets de importação de sensores): - Campos de umidade do solo: wm1_umidade_solo_1, sm1_umidade_solo_sm1, etc. - Campos meteorológicos: at_temperatura_ar, wd_direcao_vento, ws_velocidade_vento - Identificação: talhao, propriedade, nome_dispositivo, codigo_dispositivo

    SensorMixin ¶

    Mixin com operações para dados de sensores IoT do SIMIDS.

    Uso: sensores = simids.load_sensors("sensor-import:123") fazenda = sensores[sensores["propriedade"] == "Fazenda Modelo"] diario = simids.aggregate_sensors(fazenda, how="mean")

    load_sensors ¶

    load_sensors(dataset_id: str, refresh: bool = False, cache_dir: str | Path | None = None) -> DataFrame

    Load sensor readings (soil sensors and weather station), one row per reading.

    The API delivers each reading repeated for every image file of the day; duplicates are removed. Cached locally like :meth:load_images.

    Columns: dispositivo, codigo, tipo ("solo"/"estacao"), propriedade, talhao, data_hora, data, lat, lon and the numeric sensor fields.

    sensores = simids.load_sensors("sensor-import:123")

    sensor_locations ¶

    sensor_locations(sensors: DataFrame)

    One point per device (its most frequent coordinate) as a GeoDataFrame in EPSG:4326.

    aggregate_sensors ¶

    aggregate_sensors(sensors: DataFrame, how: str | dict[str, str] = 'mean') -> DataFrame

    Group sensor readings per device, by day or in 30-minute slots.

    how:

    • "mean", "sum" (acumulado no dia), "min" or "max": one row per day and device.
    • "30min": one row per 30-minute slot and device (readings aligned between devices).
    • dict {campo: função} for per-field daily rules; other fields use the mean. Ex.: {"rm_pluviosidade_instantanea": "sum", "at_temperatura_ar": "max"}.

    simids.aggregate_sensors(sensores, how="sum")

    cross_sensors ¶

    cross_sensors(imgs: DataFrame, sensors: DataFrame, band: str = 'NDVI', radius: float = 10, max_size: int | None = 2000, how: str | dict[str, str] = 'mean') -> DataFrame

    Cross soil sensors, weather station and an image index, per flight date × soil sensor.

    For every accessible scene with band, the index is averaged in a circle of radius meters around each soil sensor inside the image, and joined with that sensor's soil readings and the station's weather (columns prefixed estacao_), grouped as in :meth:aggregate_sensors (how="30min" gives one row per 30-minute slot, the index repeated in the day).

    tabela = simids.cross_sensors(imgs, sensores, band="NDVI", radius=10) tabela[["NDVI_media", "sm1_umidade_solo_sm1"]].corr()

    clean_sensors ¶

    clean_sensors(sensors: DataFrame, verbose: bool = True, position_window: str = '15D', min_stay_days: int = 7) -> DataFrame

    Readings ready for analysis: impossible values removed and one position per device and day.

    • Values outside :data:VALID_RANGES become NaN (e.g. dew point -273 °C, 13 110 mm of rain in one reading).
    • Soil readings with every level and the soil temperature at 0 are sensor failures and become NaN.
    • The same reading imported twice (same values, a few seconds apart in the device's reading interval) is kept once, so rain is not counted twice.
    • lat/lon become one position per device and day: single readings carry stray coordinates, and soil sensors are moved between areas. Stations take their most frequent coordinate; soil sensors the most frequent of a 15-day window around the day (position_window). A position kept for fewer than min_stay_days days with readings is a flip in the API data, not a move: those days take the position of the longer neighbouring period. Moves that last longer, between farms or inside one, are kept. posicao_conf is the share of the window's readings at the chosen position (low: ambiguous position in the API).

    base = simids.clean_sensors(simids.load_sensors("sensor-import:123"))

    filter_sensors ¶

    filter_sensors(sensors: DataFrame, start: Any = None, end: Any = None, area: Any = None, buffer_m: float = 0, clean: bool = True, min_stay_days: int = 7, **criteria: Any) -> DataFrame

    The readings of an analysis: period, area and devices, applied once to all the data.

    • start/end: dates included (end enters whole).
    • area: GeoDataFrame, shapely geometry (EPSG:4326), file path or (lon_min, lat_min, lon_max, lat_max); buffer_m widens it. Uses the position of each day, so a device that was moved counts only while inside.
    • criteria: columns, as in ImageCollection.filter: text ignores case and accepts part of the name, a list matches any value (dispositivo=["HOBO 2", "Estação Norte"], tipo="solo").
    • clean: runs :meth:clean_sensors first; min_stay_days is its minimum stay for a soil sensor position.

    The propriedade label of soil sensors does not always match where they are; area filters by the coordinates.

    base = simids.filter_sensors(sensores, start="2025-03-01", end="2026-08-31", area=roi, buffer_m=500)

    sensor_summary ¶

    sensor_summary(sensors: DataFrame) -> DataFrame

    One row per device: type, readings, period, reading interval and last position.

    weather_series ¶

    weather_series(sensors: DataFrame, freq: str = 'D') -> DataFrame

    Rain and temperature of the weather stations, one row per station and period.

    The stations name the same quantity differently; the columns are unified:

    • chuva_mm: rain summed in the period (rm_pluviosidade_instantanea or rn_precipitacao_acumulada, both in mm per reading).
    • temp_media, temp_min, temp_max: air temperature (°C). Stations without an air thermometer (HOBO) get it from dew point and relative humidity (Magnus formula); temp_calculada marks those rows.
    • ponto_orvalho, umidade_rel: missing ones are computed the same way.
    • leituras and cobertura: share of the expected readings received (0–1). A day with low coverage underestimates the rain.

    freq: "30min", "h", "D", "W", "MS" (month)… data is the period start.

    clima = simids.weather_series(base, freq="D")

    soil_moisture ¶

    soil_moisture(sensors: DataFrame, freq: str = 'D') -> DataFrame

    Soil moisture of the soil sensors, one row per sensor and period, with the position of that period.

    sm1, sm2, sm3: moisture (%) of the sensor's three levels (sm1_umidade_solo_sm1…); sm_media: their mean; temp_solo: soil temperature (°C).

    solo = simids.soil_moisture(base, freq="D")

    sensor_dashboard ¶

    Interactive dashboard of weather stations and soil sensors over time (ipyleaflet + ipywidgets).

    SensorDashboard ¶

    SensorDashboard(weather: DataFrame | None, soil: DataFrame, layer: str = 'sm_media', height: str = '520px')

    Map of the sensors on a chosen day, with rain/temperature and soil moisture charts.

    Soil sensors are colored by the chosen layer at their position on that day; stations are the blue circles. Click a marker to chart it. The slider (or ▶) walks through the days.

    clima = simids.weather_series(base, freq="D") solo = simids.soil_moisture(base, freq="D") simids.SensorDashboard(clima, solo)
