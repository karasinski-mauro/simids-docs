    Conexão e credenciais¶

    Conectar¶

    import simids

simids.initialize()

    Na primeira vez são pedidos:

    1. a URL da API do SIMIDS (fornecida pela equipe da plataforma);
    2. o token — lido com getpass, não aparece no notebook;
    3. o workspace (opcional).

    Eles ficam salvos em credentials.json, legível só pelo seu usuário. Nas próximas vezes nada é perguntado. Para trocar de token, workspace ou URL:

    simids.initialize(overwrite=True)

    Nunca coloque o token no notebook

    Não escreva o token em células, arquivos do repositório ou variáveis de ambiente salvas no git. Se um token vazar, gere outro na plataforma.

    Funções direto no módulo¶

    Depois de simids.initialize(), as funções da conexão ficam no próprio módulo, como no Earth Engine:

    imgs = simids.load_images("sensor-import:123")
sensores = simids.load_sensors("sensor-import:123")
b = simids.load_bands(imgs, ["NIR", "RED"])

    O initialize() também devolve a conexão, para código que precise passá-la adiante:

    client = simids.initialize()
client.load_images("sensor-import:123")

    A lista completa está em Funções do módulo simids.

    Onde ficam credenciais e cache¶

    A pasta .simids é escolhida nesta ordem:

    1. variável de ambiente SIMIDS_HOME;
    2. a pasta .simids mais próxima no diretório atual ou acima dele (como o git encontra o .git);
    3. ~/.simids.

    Em servidores onde o diretório pessoal é apagado ao reiniciar (JupyterHub em container), crie a pasta uma vez num disco persistente, fora de qualquer repositório git:

    mkdir -p /caminho/persistente/.simids

    e abra os notebooks numa pasta abaixo dela, ou defina SIMIDS_HOME.

    Cache dos datasets¶

    Os dados de cada dataset ficam em .simids/datasets/<dataset>/:

    Arquivo Conteúdo
    rows.pkl.gz todas as linhas do dataset (load_dataset)
    images.pkl.gz catálogo de imagens (load_images)
    sensors_v3.pkl.gz leituras de sensores (load_sensors)

    São compartilhados por todos os notebooks do ambiente e só são baixados de novo quando o token, o workspace ou a URL mudam, ou com refresh=True:

    imgs = simids.load_images("sensor-import:123", refresh=True)

    Sem arquivo (CI, scripts, servidores)¶

    Se SIMIDS_API_TOKEN estiver definida, ela é usada e nada é gravado em disco:

    export SIMIDS_API_URL=https://...    # obrigatório
export SIMIDS_API_TOKEN=...          # obrigatório
export SIMIDS_WORKSPACE=...          # opcional

    Autenticação manual¶

    import getpass, simids

simids.authenticate(
    api_token=getpass.getpass("Token: "),
    workspace_user_id="meu_workspace",
    api_base_url="https://...",
    overwrite=True,
)
simids.initialize()

    Remover credenciais¶

    simids.clear_credentials()

    Erros comuns¶

    Mensagem Causa
    SIMIDS não foi inicializado rode simids.initialize() antes das outras funções
    SIMIDS_API_TOKEN está definida, mas falta SIMIDS_API_URL defina também a URL da API
    AuthError o token foi recusado; o arquivo salvo é removido — rode simids.initialize() de novo para informar outro token
    AccessDenied o dataset não está liberado para o seu workspace
