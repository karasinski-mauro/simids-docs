    Mapas e área de interesse¶

    Há dois mapas, com a mesma forma de adicionar camadas:

    simids.Map simids.DrawMap
    Biblioteca folium (HTML estático) ipyleaflet (Jupyter widget)
    Desenhar áreas não sim — m.roi volta para o Python
    Controle de datas não add_time_slider
    Salvar como HTML m.save("mapa.html") —
    Fundo satélite, híbrido, terreno, OpenStreetMap satélite

    Adicionar camadas¶

    m = simids.Map()
m.add_layer(ndvi, {"min": 0, "max": 1, "palette": "RdYlGn"}, "NDVI calculado")
m.add_layer(b["NIR"], {"palette": "gray"}, "NIR", shown=False)
m.add_layer(talhoes_gdf, name="Talhões")          # GeoDataFrame
m.add_layer_control()
m

    vis_params para rasters:

    • min / max: faixa da escala de cores (padrão: percentis 2–98);
    • palette: nome de colormap do matplotlib ("RdYlGn", "viridis") ou lista de cores;
    • bands: três posições (a partir de 0) para mostrar como RGB em arrays de várias bandas.

    Imagens de uma coleção já têm cores padrão por banda (NDVI, NDRE, GLI, VARI, GRVI, MPRI, EXG e RGB):

    m.add_layer(img.select("NDVI"))

    Um raster do SIMIDS direto pelo object_key:

    m.add_raster(dataset_id, object_key, name="Ortomosaico")

    Desenhar uma área de interesse¶

    m = simids.DrawMap()
m.add_layer(img.select("NDVI"), name="NDVI")
m                    # use a ferramenta de polígono ou retângulo no canto do mapa

    Na célula seguinte:

    roi = m.roi          # GeoDataFrame (EPSG:4326), uma linha por forma, com area_ha

    A área serve para load_bands(..., roi=roi), zonal_stats(..., roi), colecao.series(roi, ...) e filter_sensors(..., area=roi).

    Rodar o notebook inteiro sem desenhar

    simids.example_roi(raster, size_m=100) cria um quadrado de 100 m num pixel válido perto do meio do raster — útil para executar o notebook do início ao fim antes de desenhar a área de verdade.

    Navegar pelas datas¶

    m = simids.DrawMap()
m.add_time_slider(colecao, "NDVI")
m

    A data mais recente aparece primeiro; as outras são baixadas em segundo plano (prefetch por vez, da mais nova para a mais antiga), então mover o controle fica instantâneo quando elas terminam. prefetch=0 baixa uma data só quando ela é escolhida.

    Centralizar¶

    m.center_object(ndvi)                       # GeoArray ou GeoDataFrame
m.center_on((-61.03, 2.32, -61.00, 2.35))   # (oeste, sul, leste, norte) em EPSG:4326

    center_on calcula o enquadramento no Python, então funciona antes de o mapa aparecer na tela.
